# AI 기반 반려동물 피부질환 분류 및 위치 기반 동물병원 매칭 시스템 🐕

## 팀원

- 이민아
- 송은주
- 장승기

## 1. 프로젝트 목적

- 1인 가구의 증가와 함께 반려동물을 키우는 가구가 지속적으로 늘어나고 있으며, 이제는 1인 가구 뿐만 아니라 일반 가정에서도 반려동물 양육이 보편화됨
- 하지만 반려동물은 스스로 증상을 말할 수가 없어, 보호자가 반려동물의 질환 유무나 불편함을 초기에 정확히 인지하는 것이 어려움
- 이로 인해 피부 질환이 심각하게 악화된 후 뒤늦게 동물병원을 방문하게 되어, 반려동물의 고통이 커지고 보호자의 진료비 부담이 크게 증가하고 있음
- 따라서 반려동물 피부 질환을 조기에 분류 및 진단하고, 위치 기반으로 가까운 동물병원을 안내하여 신속한 대응을 돕는 시스템 필요

## 주요 기능

- 피부질환 이미지 분류
- 진단 기록 저장
- 캘린더 관리
- 동물병원 안내
- 맞춤형 건강관리 팁 제공
