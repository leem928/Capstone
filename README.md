# AI 기반 반려동물 피부질환 분류 및 위치 기반 동물병원 매칭 앱 🐕

## 프로젝트 소개

반려견 및 반려묘의 피부 이미지를 분석하여 피부질환을 분류하고,
건강관리 및 병원 안내 서비스를 제공하는 AI 기반 모바일 애플리케이션입니다.

## 팀원

- 이민아
- 송은주
- 장승기

## 주요 기능

- 피부질환 이미지 분류
- 진단 기록 저장
- 캘린더 관리
- 동물병원 안내
- 맞춤형 건강관리 팁 제공

## 사용 모델

- ResNet50
- DenseNet169
- EfficientNet-B2
- EfficientNet-B7
- ConvNeXt-Tiny

## 개발 환경

- Python
- PyTorch
- Flutter
- Firebase
